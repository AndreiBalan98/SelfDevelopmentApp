Life Tracker — Phase 7 mockups

Visual reference for phase-7-spec.md. Every screen here uses only the options that were approved. Layout, spacing, colours, icons and components are the reference; the numbers are illustrative (many come from the 1–9 September 2026 export).

Where this file and the spec disagree about behaviour, the spec wins. Where they disagree about looks, this file wins.

Foundations

Dark base, one accent per tab, fixed nutrient colours used everywhere. Red means a missing log, a missed target, or an overdue backup; amber only means a backup that's getting old. The font stays Geist in the app (this file uses a system font only because it's standalone). Icons are Tabler Icons, outline set. Spec part 2.
